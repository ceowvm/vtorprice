# ВторПрайс — Telegram Mini App Demo

Рабочий статический прототип Telegram Mini App для размещения предложений по вторичным полимерам.

## Что реализовано

- сценарии «Хочу продать» и «Хочу купить»;
- категории: вторичное сырьё, гранула, полимеры, оборудование;
- форма с материалом, объёмом, городом, ценой, контактом и характеристиками;
- загрузка и локальный предпросмотр фотографии;
- валидация обязательных полей;
- отправка данных через `Telegram.WebApp.sendData()` при запуске внутри Telegram;
- автономный демо-режим в обычном браузере;
- демонстрационный каталог с фильтрами;
- адаптивный мобильный интерфейс в фирменном стиле ВторПрайс.

## Локальный запуск

Откройте `index.html` в браузере или запустите простой сервер:

```bash
python3 -m http.server 8080
```

После этого откройте `http://localhost:8080`.

## Подключение к Telegram

1. Создайте бота через BotFather.
2. Разместите приложение на HTTPS-домене или включите GitHub Pages.
3. Укажите URL приложения в настройках Menu Button / Web App у BotFather.
4. На стороне бота обработайте сообщение `web_app_data`.

Пример данных, которые Mini App отправляет боту:

```json
{
  "action": "sell",
  "category": "Гранула",
  "material": "ПП гранула",
  "volume": "20 тонн",
  "city": "Казань",
  "price": "65 ₽/кг с НДС",
  "contact": "@username",
  "details": "ПТР 25+",
  "hasPhoto": true,
  "createdAt": "2026-07-26T12:00:00.000Z"
}
```

> В текущем статическом демо фотография показывается локально, но не отправляется через `sendData`: Telegram ограничивает объём этого сообщения. В production-версии файл следует загружать в backend или отправлять боту отдельным медиасообщением.

## GitHub Pages

Workflow в `.github/workflows/pages.yml` публикует содержимое ветки `main`. После первого запуска проверьте в настройках репозитория, что источником Pages выбран GitHub Actions.
